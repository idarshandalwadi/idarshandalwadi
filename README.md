## About

Full-stack developer with eight years of experience building scalable applications for product and services teams. Most of that work sits on Spring Boot and Hibernate, with Angular on the front end and MySQL, PostgreSQL, or MongoDB for data. Shipping is part of the same job: Git, GitHub, Jenkins, and CI/CD.

- **Services.** Spring Framework, Spring Boot, Hibernate, REST, and microservice boundaries that stay understandable as a system grows.
- **Interfaces.** Angular, JavaScript, HTML, CSS, Bootstrap, and Flutter.
- **Data and delivery.** Relational and document databases, plus the Git and CI/CD workflow that gets a change into production.

Open to full-stack and product engineering roles.
